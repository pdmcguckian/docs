---
title: "Add a non-SSO User"
description: "Create a User who signs in with an email address and password instead of Workspace SSO"
---

A non-SSO User signs in to Aglide with an email address and password, rather than through your identity provider with Workspace SSO. Administrators create these Users directly in the Directory.

## Add the User

<Steps>
  <Step title="Open the Directory">
    In the Dashboard, go to [**Directory → Users**](https://dashboard.aglide.com/directory?tab=users).
  </Step>
  <Step title="Click Add new">
    Click **Add new**.
  </Step>
  <Step title="Enter the User's details">
    Fill in:

    - **First name**
    - **Last name**
    - **Email**
    - **Password**: a temporary password for the User's first sign-in
    - **Confirm password**

    <Frame>
      <img src="/images/add-password-user.webp" alt="The Add a new user form in the Directory, with First name, Last name, Email, Password and Confirm password fields" />
    </Frame>
  </Step>
  <Step title="Click Add User">
    Click **Add User**. The User is created and can sign in straight away.
  </Step>
</Steps>

## After adding the User

Aglide does **not** send an invite or setup email to non-SSO Users. There is no setup step: the User can sign in as soon as they are added, using the email and password you entered.

<Warning>
  You set the User's initial password, so you must share it with them yourself. Send it over a secure channel, and ask the User to change it as soon as they first sign in.
</Warning>
